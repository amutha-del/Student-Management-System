# Student Management System

## About the Project
The Student Management System is a simple Java console-based application designed to manage student records. It allows users to add, view, search, and delete student details.

## Features
- Add Student – Enter student ID, name, and department.
- View Students – Display all student records.
- Search Student – Find a student using their ID.
- Delete Student – Remove a student record using their ID.

## Technologies Used
- Java
- Eclipse IDE
- Scanner Class
- Arrays

## How to Run
1. Clone or download this repository.
2. Open the project in Eclipse IDE.
3. Run `StudentManagement.java`.
4. Select an option from the menu.
5. Enter the required student details.
